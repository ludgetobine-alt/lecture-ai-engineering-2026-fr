# Lecture 01 : introduction à l’ingénierie de l’IA et environnement de développement

## Objectifs de la séance

- Comprendre que l’ingénierie de l’IA met surtout l’accent sur l’utilisation de modèles comme composants et sur un cycle d’évaluation et d’amélioration, plutôt que sur la création de modèles
- Savoir utiliser soi-même l’environnement de développement du cours (GitHub Codespaces, GitHub Copilot, Gemini API)

## Points essentiels

1. **Ingénierie de l’IA** : utiliser un LLM préentraîné comme composant, le relier à des données et à des outils, puis l’évaluer et l’améliorer pour construire un système utile.
2. **Bases des LLM** : l’entrée est découpée en tokens et le texte est généré en prédisant les tokens suivants. Les sorties varient de manière probabiliste (paramètre de température, `temperature`). Le modèle peut produire une réponse plausible à propos de ce qu’il ignore (hallucination).
3. **Utilisation par API** : appeler Gemini API depuis Python. La clé API est secrète : l’enregistrer comme secret Codespaces, puis la lire via la variable d’environnement GEMINI_API_KEY. Ne pas l’écrire dans le code.
4. **Environnement de développement** : Codespaces crée dans le cloud un environnement conforme à la configuration du dépôt (devcontainer). L’arrêter après utilisation.
5. **Programmation avec l’IA** : écrire du code avec la complétion et le chat de Copilot. Lire et comprendre les propositions avant de les adopter.
6. **Remise du travail** : créer un fork du dépôt du cours → travailler dans une branche par séance → remplir lectures/NN/answer.md → créer une PR vers main dans son propre fork.

## À expérimenter

- Poser des questions à un LLM sans outils avec app/ask.py et vérifier qu’il ne connaît pas les informations propres au cours (il répond qu’il ne sait pas, ou fait des suppositions à partir de généralités). Des outils amélioreront cela dans Lecture 03
