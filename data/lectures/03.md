# Lecture 03 : agents d’IA

## Objectifs de la séance

- Comprendre la structure de base d’un agent d’IA : « modèle + boucle + outils »
- Créer et exécuter soi-même un agent d’aide à l’apprentissage utilisant des outils avec Pydantic AI

## Points essentiels

1. **Agent** : système qui atteint un objectif grâce à une boucle dans laquelle un LLM appelle des outils, examine les résultats et décide de l’action suivante.
2. **Outils** : le modèle lit le nom, la description et les types des arguments d’un outil, puis demande son appel. Le programme l’exécute. La formulation de la description influence le comportement.
3. **Coût de la boucle d’agent** : plusieurs appels au LLM pour une question ont un impact important sur le temps de réponse, les coûts et les limites de débit.
4. **Harnais** : programme qui entoure un LLM d’une boucle, d’outils et d’une interface, comme Claude Code ou Pi. Pi est un harnais léger limité à quatre outils intégrés : read, write, edit et bash.
5. **Frameworks** : Pydantic AI (parcours principal) définit les outils et les sorties avec des types et permet de tester sans appel API avec TestModel. ADK est le framework de Google ; adk web permet de suivre visuellement son fonctionnement.
6. **Garde-fous et intervention humaine (Human-in-the-loop)** : pour les opérations difficiles à annuler, comme les écritures, limiter les autorisations ou insérer une validation humaine.

## À expérimenter

- Poser à un agent capable de chercher dans le glossaire la même question que dans Lecture 01 et constater l’amélioration de la réponse
- Lire quels outils ont été appelés et avec quels arguments
- Ajouter un outil
