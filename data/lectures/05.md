# Lecture 05 : outils externes et MCP

## Objectifs de la séance

- Comprendre comment extraire les outils d’un agent des fonctions internes de l’application pour en faire des services externes
- Expérimenter le partage d’outils entre différents clients avec MCP (Model Context Protocol)

## Points essentiels

1. **Outils externes** : fonctionnalités extérieures à l’agent : récupération de pages Web, manipulation de fichiers, bases de données, API tierces, etc. Les fonctions outils de Lecture 03 étaient dans le même processus ; les outils externes s’appellent entre processus ou entre machines.
2. **Rôle de MCP** : convention commune entre le fournisseur des outils (serveur MCP) et leur utilisateur (client MCP : agent ou éditeur). Un seul serveur permet d’utiliser les outils de la même manière depuis tout client compatible.
3. **Ce que le serveur expose** : nom, description et schéma des arguments des outils. Le modèle les lit pour décider des appels. Les mêmes informations que la docstring de Lecture 03 arrivent depuis un autre processus.
4. **Transport** : avec stdio, le client démarre le serveur comme sous-processus et communique via les entrées/sorties standard. Avec Streamable HTTP, le serveur écoute à une URL et accepte aussi les connexions d’autres machines.
5. **Serveurs prêts à l’emploi** : il suffit d’inscrire des serveurs publiés (fichiers, récupération Web avec fetch, GitHub, etc.) dans un fichier de configuration au format mcpServers. L’utilisateur décide des autorisations : écriture de fichiers, envoi de données à l’extérieur, etc.
6. **Espaces de noms et coût** : les outils de plusieurs serveurs se distinguent par « nom_du_serveur_nom_de_l’outil ». Plus d’outils signifie plus de descriptions transmises au modèle, ce qui influence la précision du choix d’outil et le nombre de tokens par appel.
7. **Sécurité** : un serveur MCP exécute du code arbitraire. Ne pas configurer de serveur de provenance inconnue. Pour une exposition HTTP, réfléchir à l’authentification et au périmètre d’accès (le transfert de ports Codespaces est privé par défaut).

## À expérimenter

- Exposer l’outil de glossaire de Lecture 03 sur un serveur MCP et l’utiliser depuis le même agent via MCP
- Exposer un outil
- Ajouter un serveur fetch prêt à l’emploi en modifiant uniquement la configuration
